Load a skill by `name`, as the skills index lists it: its whole body, kept for the session.

Load one when its description matches the work in front of you. The body is its author's
instructions on how to work here: follow them, and never cite them as evidence of what the code
does. Only a check shows that.

A load is refused, and loads nothing, when the name is not in the index (the answer offers the
near ones), when the body is over the size a skill may be, or when the session already holds as
many skills as it may. You cannot unload one: say which you believe is finished, and the user
decides.
