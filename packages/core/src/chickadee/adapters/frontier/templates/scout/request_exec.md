Ask to run one read-only command your other tools cannot answer. `command` and `reason` are required.

The session decides, never you: a command it already ran this session comes back from
memory; past the per-call limit, or anything that installs, builds, fetches, writes or
names a secret, is refused. A granted command runs exactly as written, with the repository
read-only and the network off, and its output comes back capped.

`reason` says why the structured tools were not enough, and is recorded. A refusal is
final: do not rephrase the command to get around it. Leave what it would have answered in
`unresolved`.
