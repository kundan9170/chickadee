Hand one task to the coding agent. With a work folder, give `task`, its id in the approved plan (T1, T2, ...): its brief is that task's file as approved. Where the work has no folder, give a `title` (one line, the commit's subject) and a `brief` (markdown, following the brief template).

A task whose file changed after the plan was approved is refused: call `plan` to approve the change first. The agent starts each task in a fresh context: its instructions, what earlier tasks committed, the brief, and the paths of the design's and the plan's files, which it may read and never write. Nothing else of yours reaches it, so the brief says where to look and what you found there. The answer is the agent's report in its own words, and the facts measured independently of it: why it stopped, the files it changed, the tests added or edited, the symbols added or removed, whether each changed file still parses, and each command it ran with its exit code. Review it with `review` before you delegate again: one task is open at a time, and `delegate` is refused while one is.
